# AWS EC2 인스턴스

해킹 시도가 여러 번 있었기 때문에, 해킹 차단을 위해서 AWS EC2 인스턴스 서버의 인바운드 ip는 모두 차단, 아웃바운드 ip, 프로토콜, 포트는 모두 허용

## tailscale

tailscale 기반 가상 네트워크를 통해 검증된 계정으로만 서버와 통신

탄력적 ip를 사용하지 않으므로, ec2 인스턴스가 중지되고 시작될 때마다 공용 ip 주소가 바뀌는데, tailscale을 사용하면 공용 ip 주소가 바뀌든 안 바뀌든 동일한 tailscale ip를 통해서 통신할 수 있음

## ssh 터널링

tailscale 가상 네트워크로 통신하면 보안이 뛰어나지만, 이 가상 ip 대신 공용 ip로 바꾸었을 때도, 네트워크 설정 혹은 암호화 설정할 필요 없이 통신하기 위해서 ssh 터널링을 구축함

로컬과 AWS EC2 인스턴스와 모니터링 데이터를 송신, 수신할 때, ssh 터널링이 사용
