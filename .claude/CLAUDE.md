
# 코드 쓰임 탐색

작성된 코드의 쓰임을 모르겠다면, 깃헙의 커밋 메시지 혹은 pr 기록을 뒤져서 찾기

# 한국어 답변

**반드시** 한국어로 답변

# 들여쓰기

들여쓰기는 **반드시** 공백(` `)으로 작성

# 주석 규칙

코드를 그대로 해석하는 주석을 **절대** 작성하지 않음. 예를 들어, `int a = 1; // a에 1을 할당` 금지
코드의 의미를 나타내는 주석을 작성. 여러 줄에 걸친 코드가 의미하는 바를 작성하거나, 코드 한 줄이 의미하는 바를 작성.
하드 코딩하지 않고, 추상적으로 작성할 것

# 텍스트 제한

텍스트 작성할 때, 허용되는 문자는 아스키 8~9, 32~126번 문자, 한글 전체, 이모지만 가능하고, 다른 문자는 제한

# 프로젝트 디렉터리

이 프로젝트는 모노리포 구조

# 로컬, 서버 통신

서버는 1개의 AWS EC2 인스턴스에서만 실행
클라이언트, 모니터링은 1개의 로컬 맥북에서만 실행

AWS EC2 인스턴스 서버의 보안그룹에서 인바운드 ip는 모두 차단, 아웃바운드 ip, 프로토콜, 포트는 모두 허용
로컬과 AWS EC2 인스턴스와 모니터링 데이터를 송신, 수신할 때, ssh 터널링이 사용
tailscale 기반 가상 네트워크를 통해 검증된 계정으로만 서버와 로컬이 통신
