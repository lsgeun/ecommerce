# 들여쓰기

들여쓰기는 **반드시** 공백(` `)으로 작성

# 주석 규칙

코드를 그대로 해석하는 주석을 **절대** 작성하지 않음. 예를 들어, `int a = 1; // a에 1을 할당` 금지
코드의 의미를 나타내는 주석을 작성. 여러 줄에 걸친 코드가 의미하는 바를 작성하거나, 코드 한 줄이 의미하는 바를 작성.
하드 코딩하지 않고, 추상적으로 작성할 것

# 텍스트 제한

텍스트 작성할 때, 허용되는 문자는 아스키 8~9, 32~126번 문자, 한글 전체, 이모지만 가능하고, 다른 문자는 제한
